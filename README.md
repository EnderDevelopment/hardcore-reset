# Hardcore Friends Mod

The Hardcore Friends Mod is designed for Minecraft servers to enhance the hardcore gameplay experience with friends. It automatically resets the world when any player dies, ensuring a fresh start for everyone. The mod clears inventories, resets health and experience, changes the world seed, and regenerates the terrain. It also teleports all players to the new spawn point, providing a seamless and fair experience for all participants.

## Install

1. Download the mod file from the GitHub repository.
2. Place the mod file in the `mods` folder of your Minecraft server.
3. Start or restart your Minecraft server to apply the mod.

## Use

1. When any player dies, the mod will automatically broadcast a message in the chat.
2. The world will reset, including clearing inventories, resetting health and experience, changing the world seed, and regenerating the terrain.
3. All players will be teleported to the new spawn point.
4. To manually reset the world, use the command `/hardcorefriends reset`.
5. To configure the mod, use the command `/hardcorefriends config`.
